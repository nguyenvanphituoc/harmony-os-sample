# UC-08 — Open a list

Actor: the user, from P1 to P2 List. Covers R3, R7, R8, R10, R11.

## Input / Output

- Input: `listId` (route parameter)
- Output: the list's item cards in `ItemOrder`, or the empty invitation

## Steps

1. The user taps a list card body (U3); `ListsViewModel.onOpen(listId)` (N17) pushes route `List` with the list id.
2. P2 shows the list's name as the title (U8, N21). `status` is Loading for the first frame, then Empty or Ready (N23).
3. `ListViewModel.items` (N22) takes only the S2 items of `listId` and orders them with `ItemOrder.sort` (N5): open first, done last, newest-created first inside each group.
4. Each item is its own card (U12). Open: `ink` text on `surface`, empty box. Done: struck through in `inkMuted` on `surfaceDone`, checked box.
5. A list with no items shows "No items yet" and "Add your first item above" (U15).
6. Back (U7, or the system Back) pops to P1 (N27).

## Invariants

- [INV-21] P2 shows the opened list's items and no other list's (R3).
- [INV-22] The item order is `ItemOrder`: done below every open item; newest-created first in each group (R7).
- [INV-23] Returning to a screen refreshes it in place without going back to Loading.
- [INV-24] The template entry stays: `EntryAbility` loads `pages/Index`, which hosts the single `Navigation`; `module.json5` and `main_pages.json` do not change (RH1).

## Error Cases

None reachable (in-memory data). If `listId` no longer exists, P2 shows the Empty branch.

## System Flow

`U3 -> N17 onOpen -> N2 Navigation route List -> P2 -> N21 / N22 / N23 -> S1 + S2 -> N5 -> U8 / U12 / U15`
