# UC-06 — Delete an item

Actor: the user, on P2 List (confirms in P4). Covers R9.

## Input / Output

- Input: `itemId: string`
- Output: `Result<void>` — `Ok` or `Err(ITEM_NOT_FOUND)`

## Steps

1. The user taps the delete icon on an item card (U14); `ListViewModel.onDeleteItem(itemId)` (N26) opens P4 with `Delete "<item>"?` (U21).
2. "CANCEL" (U23) closes P4 and keeps the item.
3. "DELETE" (U22) calls `DeleteItem(itemId)` (N11), which calls `InMemoryTodoRepository.deleteItem` (N12) and removes the item from S2.
4. P2 refreshes; when the list has no items left, the invitation (U15) shows. P1 progress follows.

## Invariants

- [INV-14] Nothing is deleted without the user confirming in P4 (R9).
- [INV-15] Deleting an item removes only that item; the list and its other items stay.
- [INV-16] The item delete icon is separate from the card body: tapping it never toggles the item (a tap anywhere else on the card toggles).

## Error Cases

| Code | When | Message / action |
|---|---|---|
| `ITEM_NOT_FOUND` | the id no longer exists | `Err`; no state change |

## System Flow

`U14 -> N26 onDeleteItem -> P4 (U21) -> U22 -> N11 DeleteItem -> N12 -> S2 -> N22 / N23 -> U12 / U15`
