# UC-03 — Delete a list

Actor: the user, on P1 Lists (confirms in P4). Covers R4.

## Input / Output

- Input: `listId: string`
- Output: `Result<void>` — `Ok` or `Err(LIST_NOT_FOUND)`

## Steps

1. The user taps the delete icon (U5); `ListsViewModel.onDelete(listId)` (N19) opens P4 with `Delete "<list>" and its <n> items?` (U21).
2. "CANCEL" (U23) closes P4 and keeps the list.
3. "DELETE" (U22) calls `DeleteList(listId)` (N8), which calls `InMemoryTodoRepository.deleteList` (N12): the list leaves S1 and every item of that list leaves S2.
4. P1 refreshes; when no list remains, P1 shows the empty invitation (U6, see UC-07).

## Invariants

- [INV-06] Deleting a list deletes all of its items and no other list's items (R4, R3).
- [INV-07] Nothing is deleted without the user confirming in P4 (R4).

## Error Cases

| Code | When | Message / action |
|---|---|---|
| `LIST_NOT_FOUND` | the id no longer exists | `Err`; no state change |

## System Flow

`U5 -> N19 onDelete -> P4 (U21) -> U22 -> N8 DeleteList -> N12 -> S1 + S2 -> N14 / N15 -> U2 / U6`
